## Do

- Keep labels short and descriptive.
- Provide helper text for input format when needed.
- Use `state="error"` with a clear error message.
- Keep placeholder as hint text, not as a replacement for label.

## Don't

- Do not rely on placeholder as the only field label.
- Do not use generic errors like "Invalid input" without guidance.
- Do not use long helper text that wraps multiple lines unnecessarily.
- Do not hide required validation feedback.
