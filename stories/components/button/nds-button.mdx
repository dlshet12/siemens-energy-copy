## Do

- Use `variant="primary"` for the main action in a section.
- Keep button labels short and action-oriented.
- Use `disabled` only when action is temporarily unavailable.
- Keep size consistent within related actions.

## Don't

- Do not place multiple primary buttons side-by-side.
- Do not use destructive style for non-destructive actions.
- Do not rely on color alone; keep text labels explicit.
- Do not mix too many sizes in one compact layout.
